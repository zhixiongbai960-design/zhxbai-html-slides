# 风格与改编规则

## 风格来源与取舍

本规则根据创建时读取的 guizang-ppt-skill、zhxbai-wechat-writing、zhxbai-infographic-cards 及 wechat-mp-publish 整理。公众号技能用于表达与品牌视觉参考，不继承发布操作。源技能以后可能变化；用户提供当前成品或修订时优先以它为准。

保留 guizang 的叙事规划、版式复用、浏览器实看与导航能力。放开只许预设主题、超大细体、频繁黑白切换、固定版式配额；这些约束服务其原有风格。新模板代码独立实现，不依赖原 skill 的文件或 CDN。

## 视觉令牌

- 主蓝 `#0052D9`，品牌底栏可渐变到 `#366EF4`。
- 白底 `#FFFFFF`，标题 `#111827`，辅助文字 `#647084`。
- 浅蓝 `#EDF3FF`，中浅蓝 `#D8E6FF`，边线 `#DCE4EF`。
- 画布直角。内部关系节点可少量使用 6–12px 圆角，沿用图解卡片语言。无阴影、无无意义装饰；不使用整页暗色封面作为默认。
- 系统无衬线中文字体。1600×900 基准下封面标题 80–96px，正文标题 54–64px，节点 28–34px，正文 24–28px，元信息 18–22px。内容多时分拆或重排，不优先缩字。
- 左右安全区 80px，顶部 52px，品牌底栏 68px，结论区与正文保持明显间距。正文最晚在 y=742 附近结束，结论从约 y=773 起。
- 页眉使用系列名称，页内容使用章节编号与主题，避免同一句话重复装饰。底栏是既有品牌落款与页码。
- 保留蓝色加粗强调，不使用下划线或公众号引用块样式。颜色只表达层级和重点，不为了节奏随机改色。

## 文字声音

结论明确，解释具体，带真实边界。每页能独立读懂，也能沿页序推进。已确认的经验可以直接陈述；未知处标明待验证。不编造客户原话、项目收入、效果、经历或统计数字。

继承公众号口吻，不机械复制长文格式。PPT 不强制 343 比例、3–6 个章节、固定三段结尾、五个标题和朋友圈文案。去掉互动号召和主持式转场，只保留对本次演讲有用的收束。

正文避免「说白了」「意味着」「本质上」「换句话说」「不可否认」「综上所述」「值得注意的是」「不难发现」。页面文案避免冒号、长破折号和英文直引号；代码语法、URL、必要技术表达不在此列。不把当前模板的某一句话变成所有主题的固定口号。

## 图形语义

递进用阶梯，分工用泳道，输入到输出用流程，反馈回到下一轮才称闭环。并列证据用对齐列，比较应有共同维度。图形承担信息，不只是把列表框起来。

概念阶梯不伪装成统计柱状图；数据图必须有真实数值、单位与来源。箭头须表达明确流向。图文关系用可编辑 HTML/SVG，不把整页栅格化成图片。纯图解无需生成装饰插画。

## 叙事演示与 SVG

叙事演示默认先减文字。屏幕让听众知道当前讲什么，详细解释由讲述者完成。不要照搬竖版高密度卡片或把文章段落放在图形旁边。每页以主要关系图与少量标签为中心；必要的真实短引语、证据和限制仍可留在屏幕。

推荐 SVG 图形区为 `viewBox="0 0 1440 420"`，图形宽 1440、高 420，顶端约 y=286，底端不越过约 y=710。它是现有画布的稳定起点，内容需要时可调整。封面可用独立小画布。不要通过 SVG 放大缩小绕过最低可读字号。

标签通常 28–38px，辅助短句约 24–28px。统一字体、基线与字重；多行使用独立 `<text>` 或 `<tspan>`，行距约 1.4。节点容器须比文字外接框更大，不能只检查标签在整个 SVG 内就认为安全。`viewBox` 与显示比例一致。

SVG 提供 `role="img"`、语义准确的 `aria-label` 或 `<title>`。每页 marker、clipPath 等 ID 唯一，避免多个 SVG 误用定义。箭头在拐角保持空间，端点不压节点标题。路径只表达实际关系；回流、并列和未确认关系分别使用清楚的结构或虚线说明。

一般不需要装饰插画。可用简单图标辅助“表达、分岔、反馈、记录、核对”等意义，但不能以四个图标代替关系图。未来设想须标明设想，不用图形的确定性遮盖文字中的不确定性。

公开模板使用通用身份与示例讲稿；不带白志雄本人经历或任一用户的私密材料。用户提供品牌与当前认可的作品时再替换。
