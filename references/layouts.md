# 叙事版式与图形选择

先判断当前页想让听众理解什么关系，再选图形。短标签承担锚点，解释放讲稿。模板有八页可直接打开的示例；其他图形可以按内容扩展，新增 CSS 一处定义。

| data-layout | 图形 | 适合内容 | 注意事项 |
| --- | --- | --- | --- |
| cover | 放射关联图 | 内容主张、资料的构成 | 封面保持大留白，关系只作主题引导 |
| benefits | 一源多分支 | 一项积累的不同用途 | 输出并列，不画成先后顺序；预测分区标明 |
| story | 分岔路径 | 经历变化、关键选择 | 不虚构经历；未决方向保留问题 |
| timeline | 观察与现实反馈 | 看法得到验证或修正 | 一次验证不能推出所有分析都准确 |
| statement | 判断、行动、反馈闭环 | 持续学习与验证 | 返回箭头明确回到判断修正，不作装饰 |
| exploration | 多来源汇入 | 多维度证据支持一个认识 | 不把“喜欢”当成“擅长”，并列维度不画成因果 |
| scenario | 场景、期待、现实、反应 | 方法拆解、需求或觉察 | 简短实例，因果不要越过已知材料 |
| triggers | 多入口汇流 | 多类变化进入一次记录 | 图标只辅助，必须有清晰标签和汇流终点 |
| record | 双泳道与分层档案 | 两类来源或责任边界 | 不混淆本人原话与 AI 分析 |
| demo | 输入与结果对照 | 现场演示和操作说明 | 示范与真实执行区分；输入用完整短片段 |
| reviews | 嵌套范围 | 月、季、年等不同观察尺度 | 概念范围不当作量化数据，图形面积不暗示比例 |
| reuse | 碎片到体系 | 资料整理、知识二次使用 | 保留来源，归拢不是证明效果 |
| practice | 语音、记录、核对路径 | 最小行动与收束 | 保留可直接使用的一句入口，不塞安装长教程 |

以下结构在通用模板中已实现：cover、benefits、statement、exploration、triggers、record、reviews、practice。路径、案例和演示版式按材料重建，不固定在同一故事上。

页面基本轴线为页眉、主题、主图、简短结论、品牌底栏。封面和收束可以减少部件。大标题不自动承担结论，主题页也可使用准确的名词短语。
