# 浏览器验证

使用现有 Node、Playwright 与浏览器；有依赖发现工具时先发现路径，不把本机路径写进技能模板。没有渲染环境时不自动安装依赖，只交付源文件并说明未验证项。

```bash
node <skill>/scripts/check_deck.cjs \
  --input <absolute-deck.html> \
  --output <absolute-private-check-directory> \
  --playwright-module <absolute-playwright-module> \
  --browser-executable <absolute-browser-executable>
```

环境能解析模块和自带浏览器时可省略最后两项。依赖为 Playwright，仅用于质检，演示文件本身没有运行时依赖。

脚本检查四种窗口下的 16:9 缩放、主要区域相交、HTML 文字越界、SVG 标签越界与彼此相撞、编号与标题字段、目录和翻页操作、讲稿逐页对应、真实全屏 API 的菜单与缩放切换、外部请求和打印可见性。它输出每页 PNG、检查报告与临时 PDF。输出目录应只存私有检查文件，不自动当成交付物。

逐页查看 PNG：

- 标题自然换行，不产生孤字；内容与页尾结论、底栏有清楚间距。
- 正文区域的大字与短标签在演示尺寸下可读；不因节点变小而挤字。
- SVG 文字不穿过节点边缘或连线，反馈路径和箭头方向准确。
- 图形表达实际关系，概念结构没有伪造刻度；本人观点与 AI 分析、事实与设想分开。
- 屏幕精简后，详细解释仍在对应讲稿里；来源和条件没有丢失。

全屏验证点击按钮进入，再用方向键翻页；菜单不可见且画布不预留 60px 空间。再次按 F 不应退出；Esc 应退出并恢复菜单，同时保持当前页、关闭弹窗，不打开目录。普通模式仍可通过目录按钮跳页。使用实际浏览器 API 测试；浏览器或宿主不支持时明确说明未验证，不以伪造全屏状态替代。

打印 PDF 需检查页数与实际 slide 数一致且逐页分页。可用已存在的 PDF 工具读取页数；脚本只生成 PDF，不假称它已经验证了分页数量。宿主浏览器可额外人工验证全屏，权限限制不等于模板失败。

修复后重跑涉及的检查。出现失败先定位内容、几何或交互问题，不隐藏元素或放宽容差以掩盖真实相撞。中文字体字形可能略超 CSS 行框，允许合理字形边界，但不能压到相邻内容。
